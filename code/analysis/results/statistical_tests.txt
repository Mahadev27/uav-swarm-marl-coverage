TEST SELECTION
------------------------------------------------------------------------------
Each seed defines one obstacle layout, replayed identically for all
three controllers, so observations are matched. The primary test is
the paired Wilcoxon signed-rank test. Mann-Whitney U, which
discards the pairing, is reported as an assumption-light
robustness check, and Welch's t so that a reader preferring a
parametric framework can confirm the conclusions hold. All p-values
within a family are Holm-Bonferroni corrected. Alpha = 0.05, n = 50
per condition, bootstrap intervals use 10,000 resamples.
